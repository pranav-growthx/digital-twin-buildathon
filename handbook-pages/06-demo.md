# Demo

> 3:00–4:00 · everyone demos · **5 minutes per person**.

---

You've built a real agent — a twin that chats like you, lives on Slack, and has real
capabilities. Last step: make it presentable, then show it on stage.

## Before demos start (~15 min polish)

### Quick voice check

Send your twin 3–4 messages on Slack (or terminal) and read the replies. If something
feels off, tell Claude Code what to change — *"too formal," "keep replies shorter," "more
sarcasm"* — and let it update the persona. One more pass if needed.

### Make sure it's running

- Slack bot running? DM it — should reply in a few seconds.
- Capabilities working? Fire off a quick test — "read my emails," "remind me in 1 minute,"
  or whatever you installed.
- If something broke during polish, paste the error to Claude. Fix it or cut it — a clean
  demo of fewer features beats a broken demo of many.

### Prep your demo messages

Have 2–3 messages ready to send live. Pick ones that show off:

1. **The voice** — something a friend would text, where the reply sounds unmistakably like you
2. **A capability** — trigger something real (read email, schedule a message, recall a memory)
3. **A follow-up** — show it remembers context from the first message

---

## Your 5 minutes on stage

Keep it tight — you have **5 minutes total**. No slides. Live demo only.

**Structure:**

1. **Introduce yourself and your twin** (~30 sec)
   - Your name, the twin's name
   - One sentence: what it does and why you built it

2. **Show the voice** (~1 min)
   - Send a message on Slack, let everyone see the reply
   - Point out what makes it sound like *you*, not generic AI

3. **Show a capability** (~2 min)
   - Trigger something real — email drafting, a scheduled message firing, a memory recall
   - Walk through what happened: "I asked it to X, it did Y"

4. **Take a question or send one more message** (~1 min)
   - If time allows, take a quick question or show one more thing
   - End with: what you'd add next if you had another hour

> **Show the real thing.** Don't read a script or fake responses. A live reply that sounds
> like *you* is the whole point. If something breaks, talk through what you built — everyone
> here knows it's a same-day build.

---

## If things go wrong

- **Twin is slow?** Talk while it thinks — explain what it's doing under the hood.
- **Something crashes?** Show your Slack thread history — the previous replies still prove
  it works. Talk through the capability even if it won't fire live.
- **Ran out of time building?** Demo what you *did* finish. A working voice with no
  capabilities is still a real demo. A personality that nails your texting style is impressive
  on its own.

**You built a real personal AI agent in one afternoon. Go show it off.**
